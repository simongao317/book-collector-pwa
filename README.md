# BookCollector

一个 SwiftUI iOS 藏书收藏管理 App 原型。

## 已实现

- 图书字段：ISBN、统一书号、自定义书号、书名、原名、丛书名、作者、作者国籍、出版时间、出版社。
- 书号规则：ISBN、统一书号、自定义书号至少填写一个；同一种书号不可重复。
- 收藏状态：
  - 已买：可标记已读、未读。
  - 未买：可标记已读、想读、待定。
- 待定规则：未买 + 待定超过 30 天会在启动时自动清理。
- 录入方式：
  - CSV/Excel 导入。
  - 扫 ISBN 条码/二维码，并尝试通过 ISBNSearch 补全信息和封面。
  - 手写录入。
- 已买图书可通过 CSV/Excel 导入、扫码导入、手写导入创建；手写导入已买图书时，必须拍摄或选择封面照片。
- 未买图书可通过手写导入创建；阅读标签支持已读、想读、待定。
- 主界面可直接切换已买/未买和阅读标签；未买图书的阅读标签会在已读、想读、待定之间循环。
- CSV 导入导出，导出的 `.csv` 可直接用 Excel、Numbers 或 WPS 打开。

## CSV 表头

```csv
书号类型,ISBN,统一书号,自定义书号,书名,原名,丛书名,作者,作者国籍,出版时间,出版社,收藏状态,已买阅读标签,未买阅读标签,录入方式
```

可选值：

- `书号类型`：`ISBN`、`统一书号`、`自定义书号`
- `收藏状态`：`已买`、`未买`
- `已买阅读标签`：`已读`、`未读`
- `未买阅读标签`：`已读`、`想读`、`待定`
- `录入方式`：`CSV/Excel导入`、`扫码导入`、`手写导入`

## 打开方式

用 Xcode 打开 `BookCollector.xcodeproj`，选择 iPhone 模拟器或真机运行。

扫码和拍照需要真机；模拟器可以测试手写录入、CSV 导入导出、搜索和筛选。

如果 Xcode 提示缺少 iOS 组件，请打开 `Xcode > Settings > Components`，安装对应的 iOS Platform / iOS Simulator Runtime。
